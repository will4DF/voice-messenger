# Voice Messenger — Python Text & Voice Chat

A simple Python-based TCP messaging application that allows:
- Real-time text chat between clients  
- Recording voice clips (voice notes) on one client, sending them over the network, and saving them on the server for other clients to download and play  

## Features

- Multi-client support via TCP sockets  
- Text messaging  
- Voice note recording (WAV format) and transmission  
- Server-side file storage for audio clips
